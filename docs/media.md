## Editor screenshot

[`images/editor-workspace.jpg`](images/editor-workspace.jpg) is an actual Safari window capture of the locally running application. The built frontend and Rust API were served together on `127.0.0.1:4300`. The source image was uploaded using the file picker; the editor was set to colour mode, 240 columns, and an inverted ramp. The preview completed successfully before capture. Browser zoom was restored to its standard size, and the screenshot shows the workspace scrolled into view.

The configured default font for this capture was the locally installed Courier New Bold. No font file is distributed. The screenshot has not been composited or regenerated with an image model.

## Input/output comparison

The source is Michelangelo’s *The Creation of Adam*, a detail showing the reaching hands:

- [Wikimedia Commons file and public-domain designation](https://commons.wikimedia.org/wiki/File:Creation_of_Adam_(Michelangelo)_Detail.jpg).
- [`images/creation-of-adam-source.jpg`](images/creation-of-adam-source.jpg): unchanged downloaded source, 1400 × 1047.
- [`images/creation-of-adam-color.png`](images/creation-of-adam-color.png): colour output, 2160 × 1620.
- [`images/creation-of-adam-bw.png`](images/creation-of-adam-bw.png): black-and-white output, 2160 × 1620.

Both output examples were generated by the shared Rust library from commit `ab563dd027ffa73b77bcf09d154ba7ee0d8778a3`, with these `AsciiOptions` overrides:

```rust
AsciiOptions {
    mode: AsciiMode::Color, // BlackAndWhite for the other example
    max_columns: 240,
    character_width: 9,
    character_height: 18,
    invert: true,
    ..AsciiOptions::default()
}
```

They use Courier New Bold at the default font size of 16, the default character ramp `@#8&o:*. ` (including the trailing space), zero contrast/brightness adjustments, and a black background. The 9:18 cell ratio compensates for the renderer’s fixed half-height row calculation. The screenshot uses the editor’s default 10:18 cells and `#080808` background, so its preview proportions differ slightly from these library examples.

PNG compression was optimised losslessly for the example outputs; decompressed image data was verified unchanged. These are genuine conversion results, with no painted-in details or image-model enhancement. Font rasterisation may differ if another font is supplied.
